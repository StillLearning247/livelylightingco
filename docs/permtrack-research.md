## The UV-resistance nuance (action item)

The PermTrack vendor pages (permtrackusa.com, govpermtrack.com) state **"rigid PVC"**
and **"does not corrode"** but do **NOT** anywhere publicly state the track is
**UV-resistant or UV-stabilized**. So the UV-resistance framing — emphasized
heavily across all 16 location pages — is currently an **inference**, not an
independently documented spec.

It is a **defensible** inference: rigid PVC / uPVC is genuinely available
UV-stabilized, and it is the same material as vinyl window frames (which resist UV
for decades). And the business owner asserted directly that it is "rigid PVC and
has UV resistance." But a skeptical customer or competitor checking public sources
will not find UV resistance documented.

**Recommendation:** confirm with the owner (who is connected to the manufacturer)
that the PermTrack PVC is genuinely UV-stabilized.
- If yes → keep the UV emphasis as-is; consider adding the verified "does not
  corrode" point and the "we make our own track" angle.
- If uncertain → soften to verified language, e.g. "weatherproof, non-corroding
  rigid PVC — the same material family as vinyl window frames," and drop explicit
  "UV-resistant" until a spec sheet exists.

## Notable discovery: vertical integration

**PermTrack is manufactured by Jrowe Inc** (confirmed). LivelyLightingCo's lead is
named **Jakob Rowe** ("Jrowe" = J. Rowe). If that connection is real, the company
**manufactures the very mounting track it installs** — a strong, verifiable
differentiator currently **unused** on the site. Worth confirming and adding.

## Other findings

  all — our material claims are net-new (accurate) additions.

  "500-mile service radius" — both **refuted**. Good that the site never used them.
- The site's homepage says "Govee" (not the "Govee Pro / Govee Prism" sub-lines we
  added at the owner's direction) — owner-directed, so fine, but note the public
  source only shows "Govee."
- Competitor track specs (Trimlight, Jellyfish, Gemstone/Astoria, Oelo) could
  **not** be verified in this pass — treat the compare-page details as
